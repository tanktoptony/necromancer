NECROMANCER: FIRST DAWN — VANIA PASS 0.7 SETPIECE CIRCUIT

This pass expands the Plague Barge into a more authored opening level inspired by the pacing qualities of great action-adventure and metroidvania openings: larger spaces, scenic reveals, quiet traversal between encounters, an ability gate shown before the ability, a committed lower route, a relic acquisition, a vertical return, a shortcut, and a broad exterior finale.

CONTROLS
A/D or arrows — Move
SPACE / W / Up — Jump
F / left click — 3-hit attack combo
E — Raise corpse / claim item
Q — Grave Hook / test or tear Rib Gate / pull light enemy
C — Army command (Follow / Hold / Assault)
M — Map
H — Help
T — Dismiss current note
F3 — Collision overlay
R — Restart at checkpoint

0.7 LEVEL FLOW
1. Receiving Hold — quiet opening combat and first corpse.
2. Quarantine Gallery — much larger interior with an optional vertical route.
3. Rib Gate — the player reaches and tests the bone gate BEFORE finding the Grave Hook.
   A 90px broken hatch can be jumped to inspect the gate or dropped through to continue.
4. Drowned Hold — committed lower route across four visible decks.
5. Chain Crypt — Grave Hook acquisition and checkpoint.
6. Winch Shaft — first required Hook traversal.
7. Upper Orlop — Hook deposits the player on the far side of the Rib Gate; tear it open to create the shortcut.
8. Ossuary Deck — wide exterior set-piece encounter and level exit.

MESSAGE PACING
Ordinary flavor notes no longer build an endless queue. Only one ordinary note may wait behind the current one, repeated combat jokes have cooldowns, and important progression/tutorial notes replace the queue deliberately.

COLLISION RULES
F3 shows the live overlay:
Green = solid world
Cyan = normal one-way platform
Violet = intentional Grave Hook landing
Red = hazard
White outline = player
Red outline = hostile
Mint outline = friendly

Normal mandatory jumps are kept within the current 56.9px jump-height envelope. The high gallery shelves and the upper winch shelf are intentionally Hook-gated.
